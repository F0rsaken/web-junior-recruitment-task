# Zadanie rekrutacyjne na Web Junior Developera w KOLEO

Celem tego zadania jest stworzenie prostej aplikacji webowej wyświetlającej listę filmów w uniwersum Star Wars. Szkielet aplikacji jest już przygotowany, a Twoim zadaniem jest tylko dodanie brakujących funkcjonalności.

## Funkcjonalności:

- wyświetlanie listy filmów
- kafelek filmu zawiera:
	- tytuł
	- reżysera
	- producenta
	- rok wydania
	- lista postaci w tym filmie
- lista postaci w filmie jest listą linków do stron postaci
